# 智邻 · 业委会工作台

浏览器交互原型，静态入口 dist/index.html。当前本地预览：http://127.0.0.1:4173/。

## A0 入驻与建档

手机号与演示验证码登录 → 个人姓名 → 建档材料 → 档案与成员核对 → 提交 → 主任或副主任认领身份并确认锁定 → 工作台。

- 协助人员可提交，不自动获得成员权限。至少录入一名主任或副主任手机号。
- 支持备案表、社区证明、盖章模板（提供文本模板下载），多图片或 PDF；真实文件手动填录，示例预填。
- 唯一主任、手机号重复、备案编号重复、小区重复和换届提示。
- 已认领成员再次登录直接进入；已过期任期不授予业务访问。
- 主任、副主任维护未绑定手机号；已绑定号码不得直接替换。
- 锁定保存原始材料、字段快照、操作人及时间，预留三类空台账。
- 未匹配用户可保存本地加入申请；不会发送消息或自动授权。
